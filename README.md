# インセイン キャラクター駒生成ツール for ココフォリア

「逢魔人の名簿（キャラクターシート倉庫）」の共有URLから、ココフォリアへ貼り付けられるキャラクター駒JSONを生成する非公式ツールです。

## 使い方

1. `index.html` をブラウザで開きます。
2. インセインのキャラクターシート共有URLを貼ります。
3. 「読み込む」を押します。
4. 内容を確認・修正します。
5. 「ココフォリア用データをコピー」を押します。
6. ココフォリアの盤面で `Ctrl + V` します。

## GitHub Pages で公開する

このフォルダ内の `index.html` / `style.css` / `app.js` をGitHubリポジトリ直下へ置き、Settings → Pages → Deploy from a branch → `main` / `(root)` を選択してください。

## 現在の初版仕様

- 名前、PL、年齢、性別、職業
- 生命力 / 正気度
- 好奇心 / 恐怖心
- 習得特技
- アビリティ
- キャラクター設定メモ
- 参照URL
- ココフォリア Clipboard API 形式JSON

## URL取得について

キャラクターシート倉庫側がブラウザからの外部アクセスを制限した場合、URL直接読み込みがCORSで失敗することがあります。その際は画面の「URL読み込みが失敗した場合」からJSONを貼り付けて利用できます。

この初版では項目名の揺れに対応するため、複数の一般的なキー名を吸収するようにしています。実際の「逢魔人の名簿」JSONを1件確認できれば、項目マッピングを完全固定して精度をさらに上げられます。
