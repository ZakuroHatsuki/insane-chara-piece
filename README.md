# インセイン キャラクター駒生成ツール v0.2

キャラクターシート倉庫のインセイン用キャラクターシートURLから、ココフォリア用キャラクターJSONを生成する非公式ファンメイドツールです。

## v0.2
- URL読み込みを fetch から JSONP に変更（CORS対策）
- edit.html / display 系URLの `key=` を自動取得
- 誤表記を修正
- 複数世代の項目名をある程度吸収

## 使い方
1. キャラクターシート倉庫のインセイン用キャラクターシートURLを貼る
2. 「読み込む」
3. 内容を確認
4. 「ココフォリア用データをコピー」
5. ココフォリア盤面で Ctrl+V

※ インセインおよびキャラクターシート倉庫の公式ツールではありません。
